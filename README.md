# My Family for Teachers

Interactive English games for young learners (ages 5–6). The first screen lets the teacher choose a topic:

- **Family members:** mum, dad, grandma, grandpa, sister, brother, baby brother, baby sister, uncle, aunt, cousin.
- **Body parts:** face, eyes, ears, nose, mouth, hair, arms, body; tall, short, thin, fat, curly, straight.
  Language: *Who is she? She's my mum. She is tall. She has got curly hair. What colour eyes has she got?*
  Activities: Funny Body, Mystery Door, Magic Paint (Easy / Medium with microphone), Design your character.

Made for classroom smart boards; also works on computers, tablets and phones.

## Features
- **Natural recorded voice:** every instruction and sentence is a recorded clip (`assets/audio/`), so it sounds the same on every device. Children's names use the device voice.
- **Speaking step:** after a correct answer the class says the sentence out loud ("Who is she? She is my mum."); the teacher presses *We said it!* to give the star.
- **Magic name picker:** add your class list in *Settings → Names*; names float around a magic hat and the picked name is spoken. Everyone gets one turn per round; absent children can be skipped.
- **Star reward:** tap the children who are behaving well, then *Star draw!*
- **Settings:** classroom / home mode, teams, voice, speed and the words to practise.
- No reading needed: every instruction is spoken.

## Privacy
Names, stars and settings are saved only in the browser of the device you use (localStorage). Nothing is sent to a server.

## Publish with GitHub Pages
1. Upload the contents of this folder (`index.html`, `assets/`, `favicon.svg`, `.nojekyll`, `README.md`) to a public repository.
2. Repository **Settings → Pages → Build and deployment**: Source *Deploy from a branch*, Branch *main*, folder */ (root)*, then **Save**.
3. After a minute or two the site is live at `https://<username>.github.io/<repository>/`.

Works offline too: download the folder and open `index.html` in Chrome or Edge.
